**웹브라우저 환경에서 별도의 무거운 전용 서버 없이 WebRTC DataChannel을 활용하면 완벽하게 1:1 P2P 멀티플레이가 가능합니다.**  
잠수함 소나전은 1인칭 슈터(FPS)처럼 초당 60\~120회의 고속 동기화가 필요한 장르가 아니라, **초당 1\~5회 정도의 기동 상태(좌표, 침로, 속도, 수심, 방출 음향 소음원)만 주고받으면 충분한 저대역폭 시뮬레이션**이기 때문에 브라우저 P2P 환경에 가장 적합한 게임 장르 중 하나입니다.

### **1\. WebRTC 기반 1:1 멀티플레이 구조**

웹 환경에서 1:1 대전을 구현하는 가장 가볍고 효율적인 방식은 WebRTC DataChannel (Peer-to-Peer)입니다.

\[플레이어 A (방장 / Host)\]                                      \[플레이어 B (게스트 / Client)\]  
         │                                                                   │  
         ├─── (1) 초기 방 생성 시 Session SDP/ICE 교환 (초경량 시그널링) ───┤  
         │                                                                   │  
         ▼                                                                   ▼  
   \[WebRTC P2P DataChannel 직결 연결 성공 (이후 중앙 서버 불필요 / 브라우저 간 직접 통신)\]  
         │                                                                   │  
         ├─── (A의 기동/소음원 브로드캐스트: 2\~5Hz) ────────────────────────\>│  
         │\<─── (B의 기동/소음원 브로드캐스트: 2\~5Hz) ────────────────────────┤  
         │                                                                   │  
         ├─── (어뢰 발사, 핑 발사, 미끼 전개 등 이벤트 즉시 전송) ───────────\>│

* **서버 유지비 제로화:**  
  * 연결 수립을 위한 최초 시그널링(SDP 교환) 단계만 무료 클라우드(Cloudflare Workers, Supabase Realtime, Firebase, 혹은 공유 초대 코드 복사/붙여넣기 방식)를 거치면, **실제 대전 중에는 모든 데이터가 두 브라우저 사이에서 직접 암호화 통신**됩니다.  
* **낮은 지연 시간(Low Latency):**  
  * WebRTC DataChannel의 ordered: false, maxRetransmits: 0 (UDP 모드) 옵션을 사용하면 웹 소켓보다 훨씬 빠른 지연 시간으로 패킷을 주고받을 수 있습니다.

### **2\. 패시브 소나전 특화 네트워킹 아키텍처 (Acoustic State Sync)**

잠수함전 멀티플레이는 상대방의 '화면'을 동기화하는 것이 아니라, **'상대가 바닷속에 방출한 소음 파라미터'만 동기화**하면 됩니다. 각자의 브라우저가 수신된 상대방의 소음원을 바탕으로 자체 DSP/셰이더 엔진을 돌려 워터폴과 오디오를 렌더링합니다.

* **동기화할 핵심 데이터 페이로드 (초당 2\~5회 전송, 수십 바이트 수준):**  
  JSON  
  {  
    "timestamp": 1726000000,  
    "position": \[x, y, depth\],  
    "velocity": \[vx, vy, vz\],  
    "acousticState": {  
      "rpm": 120.5,             // 스크루 회전수 \-\> DEMON 동기화  
      "cavitation": 0.45,       // 광대역 소음 레벨 \-\> BASS 동기화  
      "machineryHarmonics": \[60, 120, 180\], // LOFAR 토널  
      "towedArrayDeployed": true // 예인 소나 전개 여부  
    }  
  }

* **이벤트 기반 데이터 (발생 시 즉시 전송):**  
  * 능동 핑 발사 (Active Ping: { freq: 3.5kHz, beamDir: \[az, el\], power: 220dB })  
  * 어뢰 사출 (Launch Torpedo: { id, pos, vector, wireGuided })  
  * 음향 기만기/디코이 사출 (Deploy Decoy: { pos, signature })

### **3\. 방 생성 및 접속 UX 방식**

* **초대 링크(Invite Link) 방식:**  
  * 방장(Host)이 \[1:1 전술 대전 생성\]을 누르면 짧은 룸 코드(예: BLACKTIDE-7X9) 또는 URL 링크가 생성됩니다.  
  * 상대방이 해당 링크로 브라우저에 접속하면 WebSocket/시그널링을 통해 즉시 P2P 터널이 뚫리고 작전이 시작됩니다.  
* **오프라인/클라우드리스 모드 (SDP 텍스트 복사):**  
  * 아예 시그널링 서버조차 두지 않고, 생성된 초대 텍스트(SDP Offer)를 디스코드나 메신저로 복사/붙여넣기하여 연결하는 완전 서버리스 모드도 구현 가능합니다.

### **4\. 대전 전술 룰셋 제안 (1:1 Duel Scenarios)**

* **배틀스페이스 (해역 환경):**  
  * 양 플레이어가 동일한 해저 지형(해산/협곡)과 수온약층(SVP 레이어) 맵에 배치됩니다.  
* **비대칭 침묵전:**  
  * 먼저 소음을 내거나 무리하게 고속 항진하는 쪽이 상대방 BASS/LOFAR에 노출됩니다.  
  * 상대방의 오차 타원(히트맵)을 좁히기 위해 과감히 변침 기동을 할지, 아니면 약층 밑에 숨죽여 도청할지 결정하는 극한의 심리전이 펼쳐집니다.  
* **어뢰 전선 유도 및 회피:**  
  * 발사된 유선 유도 어뢰를 조종하면서, 자신의 어뢰 발사음 때문에 노출된 위치를 피해 긴급 회피 기동을 수행하는 현대 잠수함전의 진수가 완성됩니다.

PeerJS나 simple-peer 같은 경량 라이브러리를 사용하면 수십 줄의 자바스크립트 코드만으로도 즉시 프로토타입 1:1 통신망을 구축할 수 있습니다.

# 물리 상수 시트 (Physics Constants Sheet)

> **목적:** 멀티플레이 동기화의 **단일 사실 출처(single source of truth)**.
> 모든 클라이언트가 이 상수 시트의 값으로 동일한 물리를 계산해야 한다.
> `dsp-core` Rust 크레이트의 구현이 이 문서와 일치해야 하며,
> 상수 변경 시 **코드와 이 문서를 함께** 수정한다.
>
> 구현 위치: `dsp-core/src/physics/mod.rs`, `dsp-core/src/noise/mod.rs`.
> 검증: `npm run wasm:test` (현재 Rust 단위 테스트 37개).

## 1. 소나 방정식 (Sonar Equation)

```
SNR = SL − TL − (NL − DI)
SE  = SNR − DT
```

| 기호 | 의미 | 단위 |
|------|------|------|
| SL | Source Level (표적 음원 고유 준위) | dB re 1µPa @ 1m |
| TL | Transmission Loss (전파 손실) | dB |
| NL | Noise Level (주변 배경잡음) | dB re 1µPa²/Hz |
| DI | Directivity Index (배열 지향성 이득) | dB |
| DT | Detection Threshold (탐지 임계) | dB |
| SE | Signal Excess (신호 초과량) | dB |

- `SE > 0` → 임계 초과 탐지. `SE < 0` → 임계 미달.
- 구현: `physics::snr_db`, `physics::signal_excess_db`.

## 2. 전파 손실 TL (Transmission Loss)

```
TL(R, f) = 20·log₁₀(Rₘ) + α(f)·Rₖₘ    (Rₘ: m, Rₖₘ: km, f: kHz)
```

- 1항: 구면 발산 (geometric spreading).
- 2항: 흡수 손실 (Thorp, §3).
- 구현: `physics::transmission_loss_db(range_m, freq_khz)`.

## 3. Thorp 흡수 계수 α(f) (dB/km)

Thorp (1965) 근사. `f` = kHz, `f² = f·f`:

```
α(f) = 0.11·f²/(1 + 0.003·f²)
     + 44·f²/(f² + 4100)
     + 0.0027
     + 1e-6·f⁴/(1 + 0.04·f²)
```

| 항 | 물리적 기원 |
|----|-----------|
| 0.11·f²/(1+0.003f²) | 마그네슘 설페이트 분자 흡수 |
| 44·f²/(f²+4100) | 자유 수소 이온 흡수 |
| 0.0027 | 물 분자 기반 흡수 (고정) |
| 1e-6·f⁴/(1+0.04f²) | 고주파 보정 |

- 구현: `physics::thorp_absorption_db_per_km(freq_khz)`.
- 참고: 염분/수온 보정(DeepSound/FRS)은 M1에서 생략 — 기본 Thorp만 사용.

## 4. Knudsen 해양 배경잡음 (C₀ 모델)

Knudsen et al. (1960). `f` = Hz, `W` = 풍속 (m/s), `Nw` = 100Hz 무풍 스펙트럼 준위.

```
NL = Nw + 26.2·log₁₀(f/100) + 1.3·(f/100)
     + (40 − Nw)·log₁₀(1 + 0.03·f)
     + 0.014·√(1 + 0.4·f)
     + 20·log₁₀(1 + 3e-5·W^2.5)
```

- **C₀ (무풍) 기준: `Nw = 50`** (M1 고정값).
- 마지막 항이 풍속 스케일. `W=0`이면 0 dB.
- 구현: `noise::knudsen_noise_level_db(freq_hz, wind_speed_ms)`.

### 4.1 강우 / 함선 옵션 (게임 근사)

| 모델 | 식 | 비고 |
|------|----|------|
| 강우 | `30 + 20·log₁₀(1+R) + 20·log₁₀(f/1000)` | `R` = mm/hr, `R≤0`이면 기여 없음. 주파수·강우량에 단조 증가 |
| 함선 | `110 + 20·log₁₀(V) + 20·log₁₀(100/f)` | `V` = kt, `V≤0`이면 기여 없음. 저주파 편중, 속도에 증가 |

- 구현: `noise::rain_noise_level_db`, `noise::ship_noise_level_db`.
- **합성:** `ocean_noise_level_db`가 세원을 **전력 합성** `10·log₁₀(Σ 10^(Li/10))`
  (`noise::combine_db_levels`). 단순 dB 덧셈이 아님에 주의.

## 5. 음속 (Mackenzie 근사)

Mackenzie (1981). `t` = °C, `s` = PSU, `d` = m:

```
c = 1448.96 + 4.591·t − 0.053·t² + 0.000237·t³
    + (1.340 − 0.010·s)·(s − 35.0)
    + 0.0163·d + 0.00017·d²
```

- 구현: `physics::mackenzie_sound_speed(temp_c, salinity_psu, depth_m)`.

## 6. 수온약층 프로파일 (M1)

3분할 깊이-수온 프로파일:

| 구간 | 깊이 | 수온 |
|------|------|------|
| 표층(등온) | `0 … thermocline_top_m` | `surface_temp_c` |
| 약층(선형) | `thermocline_top_m … thermocline_bottom_m` | 선형 보간 |
| 심층(등온) | `thermocline_bottom_m …` | `deep_temp_c` |

- `SoundSpeedProfile::from_temperature`가 균등 깊이 샘플로 Mackenzie 음속을 계산.
- **음속최소층** = 프로파일 내 음속 최소값의 깊이 (약층 바닥).
  → 이 깊이 아래가 **음영 구역**.

### 6.1 음영 구역 (Shadow Zone)

직접 음선이 음속최소층에서 굴절되어 그 아래 표적까지 도달하지 못함.

```
is_in_shadow_zone = (target_depth > min_sound_speed_depth)
                    && (source_depth ≤ min_sound_speed_depth)
shadow_penalty_db = SHADOW_BASE_DB + SHADOW_GRADIENT_DB_PER_M · (target_depth − min_sound_speed_depth)
```

| 상수 | 값 | 의미 |
|------|----|----|
| `SHADOW_BASE_DB` | **40.0 dB** | 직접 경로 차단 기본 벌점 (게임 근사 — 직접 경로가 사라지고 약한 굴절/반사 경로만 남은 것 표현) |
| `SHADOW_GRADIENT_DB_PER_M` | **0.05 dB/m** | 음속최소층 아래 깊이당 추가 벌점 |

- 음영 구역 TL = 기본 TL + `shadow_penalty_db`.
- 구현: `physics::TlGrid` (`transmission_loss`, `is_in_shadow_zone`, `shadow_penalty_db`).
- ⚠ `SHADOW_BASE_DB`는 물리 측정값이 아닌 **게임 밸런스 상수**.
  음영 진입 시 SE가 임계 이하로 떨어지는 것을 보장하는 데 사용.
  멀티플레이에서 이 값이 달라지면 탐지 가능 범위가 달라지므로 반드시 동기화.

## 7. SSN-X 소나 센서 (설계 명세서 §3)

| 센서 | 기하 | 주파수 대역 | 역할 |
|------|------|-----------|------|
| 구형 보우 어레이 | DIA 8.4m, 3D 조향 | 1 kHz ~ 10 kHz | 약층 위/아래 앙각 분별, 능동 핑, 어뢰 경보 |
| 선측 플랭크 어레이 | L 40m 패널 | 200 Hz ~ 2 kHz | 좌우 광역 감시, 근거리 PRS 거리 측정 |
| 예인 선배열 (TAS) | L 800m 케이블 | 10 Hz ~ 500 Hz | 초장거리 LOFAR 토널 분석 (함속 5~8 kts 제한, 좌우 모호성) |

- DI(센서별)는 이후 M2에서 배열 기하로 계산. M1에서는 `snr_db`의 `di` 인자로 주입.

## 8. 멀티플레이 동기화 체크리스트

물리 결과가 클라이언트 간 일치하려면 아래 값이 **모두** 동일해야 한다:

- [ ] Thorp 4계수 (§3)
- [ ] Knudsen `Nw`, 풍속 스케일 상수 `3e-5`, 지수 `2.5` (§4)
- [ ] 강우/함선 근사 상수 (§4.1)
- [ ] Mackenzie 계수 (§5)
- [ ] 수온약층 프로파일 파라미터 (surface/top/bottom/deep/salinity) (§6)
- [ ] `SHADOW_BASE_DB`, `SHADOW_GRADIENT_DB_PER_M` (§6.1)
- [ ] 센서 주파수 대역·DI·DT (§7)

> 이 문서의 상수를 런타임 설정(네트워크 동기화 대상)으로 분리하는 작업은
> 멀티플레이 마일스톤(§7 개발 계획)에서 수행. 현재는 컴파일 상수.

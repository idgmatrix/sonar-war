# 수중 음향 소스 카탈로그

> 목적: SSN-X가 재현할 수중음을 빠짐없이 분류하고, 합성 파라미터의 근거와 한계를
> 추적한다. 기계 판독 기준은 `data/acoustics/catalog.json`, 형식 계약은
> `data/acoustics/schema/catalog.schema.json`이다.

## 1. 모델 경계

이 문서는 **발생원 자체가 기준 거리에서 방사하는 신호**만 정의한다.

```text
Source Model → Propagation Channel → Receiver / Array → Analysis / Output
```

- Source에 포함: 기준 거리 음압/소스 레벨, 발생 방향성, 운항 상태에 따른 변조
- Source에서 제외: TL·흡수, 도플러, 표면/해저 반사, 다중 경로, 하이드로폰/배열 응답
- 주변 소음도 물에서 저절로 생기는 상수가 아니라 분포된 발생원들의 음장이다. 구현상
  `noise/`로 묶더라도 전파·수신기 효과와 혼합하지 않는다.

## 2. 신뢰도와 상태

| 등급 | 의미 | 사용 규칙 |
|---|---|---|
| A | 동일 대상·조건의 직접 교정 측정 또는 적용 가능한 표준 | 허용 오차를 명시하고 골든 기준으로 사용 가능 |
| B | 공개 문헌의 유사 대상, 범위형 경험 자료, 변환이 필요한 측정 | 적용 조건과 변환 과정을 반드시 기록 |
| C | 게임용 가정 또는 근거가 아직 없는 값 | 사실값으로 표현하지 않고 교체 가능한 데이터로 유지 |

상태는 `inventory → research_required → parameter_baseline → implemented → validated`
순으로 진행한다. `implemented`는 합성 가능, `validated`는 목표 스펙트럼과 허용 오차를
통과했다는 서로 다른 상태다.

## 4. P0 기준선에서 확인된 사실

### 4.1 대형 상선

- 선박 방사 소음은 토널과 광대역의 합이며 주요 발생원은 추진기 캐비테이션, 선내
  기계류, 선체 주위 유동이다.
- 대형 선박은 저주파 성분이 강하고 블레이드율 관련 선이 나타나지만, 개별 선박의
  RPM·블레이드 수 없이 고정 기본 주파수를 부여해서는 안 된다.
- McKenna et al.의 현대 상선 표본은 20–1000 Hz 추정 광대역 소스 레벨 약
  `177–188 dB re 1 µPa @ 1 m` 범위를 보였다. 이는 모든 상선의 보편 범위가 아니며
  선종·속력·방향·전파 보정에 의존하는 B등급 시작점이다.
- ISO 17208-1의 `radiated noise level`은 규정 운항 조건의 원거리 RMS 측정을 1 m로
  정규화한 비교량이다. 자유장 monopole source level과 자동으로 동일시하지 않는다.

### 4.2 주변 소음

- Wenz의 고전적 분류에서 해상 교통은 대략 10 Hz–1 kHz, 바람과 표면 교란은 대략
  50 Hz–20 kHz에 기여한다.
- Wenz 곡선은 위치·시간별 단일 정답이 아니라 여러 해역의 전형적 범위다. 현재
  `knudsen_noise_level_db`가 이 범위를 실제로 재현하는지는 FFT/PSD 골든 테스트로
  별도 검증해야 한다.

## 5. 현재 DSP의 C등급 기술부채

| 구현 | 현재 가정 | 조치 |
|---|---|---|
| `source::tonal_harmonic_level_db` | 모든 고조파가 순서당 일률적으로 −6 dB | 프로파일별 선군과 레벨 편차로 교체 |
| `source::broadband_level_db` | 100 RPM에서 100 dB, 캐비테이션 0–1에 20 dB | 근거 없는 절대값. 소스 종류·속력·캐비테이션 inception 모델로 교체 |
| `noise::rain_noise_level_db` | 강우율·주파수에 단조 증가하는 임의 식 | 공개 강우 PSD 연구식과 조건별 프로파일로 교체 |
| `noise::ship_noise_level_db` | 속력 증가·저주파 편중 단일 식 | 개별 표적 소스와 원거리 교통 음장을 분리 |
| `OceanNoise` 합성 필터 | 1-pole LP와 고정 3배 RMS 보상 | 목표 PSD를 주파수 대역별로 맞추는 결정적 필터뱅크로 교체 |

기존 테스트가 검증하는 것은 주로 단조성·결정성이다. 이 표의 항목은 수치 사실성
검증을 통과하기 전까지 `validated`로 올리지 않는다.

## 6. 출처

- [ISO 17208-1:2016](https://www.iso.org/standard/62408.html) — 규정 운항 조건에서 선박 방사 소음을 비교하기 위한 측정·1 m 정규화 절차
- [Wenz, 1962, Acoustic Ambient Noise in the Ocean](https://doi.org/10.1121/1.1909155) — 주변 소음 스펙트럼과 발생원 분류
- [McKenna et al., 2012](https://doi.org/10.1121/1.3664100) — AIS와 교정 녹음을 결합한 현대 상선 1 kHz 이하 방사 소음 측정
- [BOEM Sound Source List](https://www.boem.gov/environment/center-marine-acoustics/sound-source-list) — 선박 크기별 음향 성분과 공개 문헌 범위 요약
- [Discovery of Sound in the Sea: shipping noise](https://dosits.org/science/sounds-in-the-sea/how-does-shipping-affect-ocean-sound-levels/) — 선박 소음 메커니즘과 저주파 우세에 대한 보조 설명

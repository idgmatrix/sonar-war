# 검토 후 개선 계획 — 2026-09-07

대상: 전반 검토에서 발견한 7개 문제. 기존 프리셋 변경을 포함하여 작업한다.

1. [x] DSP 링 버퍼 순환 인덱스를 공통화하고 정수/분수 지연 및 반복 순환 회귀 검사.
2. [x] 샘플 처리 중 임시 힙 할당 제거, 실제 블록 시간 기반 CPU 예산과 계측 한계 표시.
3. [x] BASS에도 수신기 주변 소음 반영. 공간 공분산이 없는 현 단계 근사를 명시.
4. [x] 실제 WASM 프리셋 출력의 주파수·클리핑·결정성 검증 및 청취 보조 경로 제공.
5. [x] 프리셋→World→DSP 어댑터로 접촉 수·좌표·자함 수심 일치. 정적 비교 장면과 동역학 구분.
6. [x] bladeRate를 파생값으로 변경하여 RPM·엽수 변경 및 복원 시 불일치 제거.
7. [x] 오디오 시작/중지/실패 정리/재시도, 초기화 완료 전 장면 선택 보존.
8. [x] Rust/TS/WASM 검사, 브라우저 실행 확인, 물리 상수·계층 계약·완료 기준 문서 갱신.

검증 원칙: 오류 수정으로 기존 골든이 변하면 원인과 독립적인 수식/샘플 검증을 먼저 확인한다.
실제 청취 개선은 테스트 통과만으로 확정하지 않는다. 합성 프리셋과 청취 보조는 실측
음원 또는 현실적인 운항 조건으로 표시하지 않는다.

후속 마일스톤: TAS, 함정 운동학, 이동 표적 R/c 이력, 음속 구조 전파 고도화는 별도
구현 단계다. 이번 작업에서는 실제 구현 범위를 명시하고 완료로 잘못 표시하지 않는다.
